## 2026-10-12 (T062)

차량 버기, 인물 Chicken Guy. 조작 익히기를 마친 뒤 신호 기다리기에서 확인함.

| 항목 | 결과 | 근거 |
|---|---|---|
| 조작 익히기 → 연습 목록 없이 신호 기다리기로 바로 이어짐(US3-2) | 예 | 조작 익히기 마친 뒤 `data-screen=practice` |
| 정지선 넘기 → 게임 전체가 멈춘 겹침 화면(멈춤 그림 + 위반 그림) | 예 | 액셀을 누른 채 달려 위반 겹침(`data-kind=violation`). 사고 장면 없음. 그림은 자리표시 도형(그림 파일은 T103) |
| 멈춤 순간 누르던 버튼이 풀림 | 예 | 손을 떼지 않았는데 액셀 버튼의 눌림 표시(`data-pressed`)가 없어짐 |
| 설명 뒤 같은 구간 처음부터 다시 | 예 | 겹침이 사라지고 차가 구간 시작 자리 |
| 정지 구역에서 멈춤 → 기다림 → 보행자 시점 안내 | 예 | 안내 중 조작 버튼 숨김, 주인공 Chicken Guy, 보행자 신호가 기다리는 쪽을 봄 |
| 카드가 소리 없이 자동으로 넘어감(US2-13) | 예 | 카드 4장이 차례로 바뀌고 끝남. 소리 기능 전(T081)이라 소리 없이만 확인 |
| 안내 뒤 출발 → 칭찬 그림 → 다음 연습(횡단 전 주변 차량 확인하기) | 예 | `data-kind=praise` 뒤 겹침 없이 다음 상황. 칭찬 음성은 T081 |
| 브라우저 오류 | 0 | 콘솔 오류·페이지 오류 없음 |

- 하지 않은 것: 소리 끈 상태와 켠 상태 비교(소리 기능 전), 실제 기기 15조합 탑승객(S2 마지막 항목, 실제 기기 확인 때), 나머지 두 연습의 브라우저 끝까지 주행(엔진 완료는 단위 테스트 SC-009가 확인), 세 연습을 마친 뒤 다시 시작하면 처음부터 다시 하는 흐름(사용자 결정 2026-10-12, 코드만 확인)
- 함께 고친 것(이 확인 중 발견): 보행자 시점 카메라가 주인공 머리와 겹침 → 세 상황 `pedestrianView.camera`를 주인공 뒤·위로. 보행자 신호가 기다리는 보행자 반대쪽을 봄 → 세 보행자 신호를 길 건너편에서 기다리는 쪽을 보게(`town.ts`)
