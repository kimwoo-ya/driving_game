## 제품의 목적

아이가 차량을 직접 운전하는 재미를 통해 보행자의 안전을 배우는 한국어 3D 게임입니다. 한국의 도로 환경에서 신호와 주변 차량을 살피는 행동을 익히고, 안전 연습을 완료한 뒤에는 보행자가 없는 전용 트랙에서 컴퓨터 차량과 경주합니다.

교육의 중심은 어린이 자신의 보행 안전입니다. 운전 체험은 운전자에게 보행자가 어떻게 보이는지 이해하고 흥미를 유지하는 수단입니다. 운전 조작에 성공했다는 이유만으로 보행 안전을 이해했다고 평가하지 않습니다.

## 대상 사용자와 이용 환경

| 구분 | 요구사항 |
|---|---|
| 3~5세 | 보호자의 도움을 받아 플레이하는 것을 기준으로 합니다. |
| 6~8세 | 짧은 안내를 따라 혼자 플레이할 수 있도록 구성합니다. |
| 읽기 능력 | 글자를 읽지 못해도 그림·음성·시범 동작으로 진행할 수 있어야 합니다. |
| 기기 | 스마트폰과 태블릿을 지원합니다. 가로 화면과 터치 조작을 기본으로 합니다. |
| 브라우저 | iPhone·iPad의 Safari와 Android의 Chrome을 지원 대상으로 합니다. |
| 언어와 배경 | 안내는 한국어이며, 도로·신호등·횡단보도·교차로는 한국 환경을 기준으로 합니다. |

현재 특정 기종은 정하지 않았습니다. 지원할 최소 OS·브라우저 버전, 대표 테스트 기기, 로딩 시간과 프레임 성능의 목표 수치는 초기 구현의 성능 점검에서 정합니다. 모든 구형 기기의 동작을 보장하는 것으로 해석하지 않습니다.

## 첫 버전의 범위

| 항목 | 포함 범위 |
|---|---|
| 교육 공간 | 신호등·횡단보도·교차로가 있는 교육용 마을 1개. 보행 안전 규칙을 보여 주기 위한 주차된 차, 버스·트럭·통학버스, 골목길과 보도 없는 길, 신호등 없는 횡단보도, 육교 또는 지하도 등 장면 요소 포함 |
| 안전 연습 | 신호 기다리기, 횡단 전 주변 차량 확인하기, 교차로의 회전 차량 주의하기. 연습마다 보행 안전 규칙을 배정하여 핵심 규칙은 매번, 추가 규칙은 다시 할 때마다 전달 |
| 레이싱 공간 | 보행자가 들어오지 않는 전용 트랙 1개 |
| 차량 선택 | `modeling/`에 제공된 차량 모델 5종 중 선택 |
| 인물 | `modeling/`에 제공된 사람 모델 3종을 마을 보행자, 차 안 탑승객, 보행자 시점 안내의 주인공으로 사용. 보행자와 주인공은 손·머리 관절이 있는 Chicken Guy로 고정하고, 아이는 차량 선택 뒤 자기 차에 태울 인물을 3종 중 선택 |
| 차량 성능 | 외형만 다르고 최고속도·가속·제동·조향·후진 성능은 동일 |
| 운전 조작 | 좌우 조향, 액셀, 브레이크, 후진 |
| 레이싱 | 컴퓨터 차량과 추월·순위·완주를 겨루는 1인 플레이 |
| 경기 길이 | 정상 주행 기준 약 5분, 1~2바퀴 |
| 소리 | 한국어 안내 음성, 동요 배경음, 위협적이지 않은 효과음 |
| 저장 | 해당 브라우저에 튜토리얼 완료 여부, 레이싱 최고 기록, 소리 설정 저장 |

온라인 대전, 로그인, 기기 간 기록 공유, 아이템, 부스터, 드리프트, 점프는 포함하지 않습니다. 첫 버전에는 차량 업그레이드·재화·유료 결제·광고·추가 트랙을 넣지 않습니다. 현실적인 요소를 사용하되 복잡한 차량 정비나 정밀 운전 시뮬레이션은 요구하지 않습니다.

## 플레이 흐름

1. GitHub Pages 주소로 접속하여 시작 화면을 엽니다.
2. 시작 버튼을 누르고 차량 5종 중 하나를 선택합니다. 차량은 처음부터 모두 선택할 수 있습니다. 이어서 자기 차에 태울 인물 3종 중 하나를 고릅니다. 인물도 처음부터 모두 고를 수 있습니다.
3. 최초 이용 시 안전 연습에서 조향·액셀·브레이크·후진을 익히고 세 가지 안전 상황을 경험합니다.
4. 필요한 안전 행동을 직접 수행하면 해당 연습을 완료합니다. 실패하면 그 구간을 반복하며 시간제한은 없습니다.
5. 모든 안전 연습을 완료하면 레이싱이 열립니다.
6. 이후에는 시작 화면에서 안전 연습과 레이싱을 선택할 수 있습니다. 차량과 인물도 다시 선택할 수 있습니다. 다시 하는 안전 연습에서는 아직 배우지 않은 보행 안전 규칙을 이어서 배웁니다.
7. 레이싱을 마치면 순위와 완주 시간을 보여 주고, 재도전하거나 시작 화면으로 돌아갑니다.

완료 기록이 남아 있는 같은 브라우저에서는 재방문 시 레이싱을 다시 열기 위해 튜토리얼을 반복할 필요가 없습니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 이전 기록을 가져오지 못합니다.

## 운전 조작과 화면

### 터치 조작

- 가로 화면의 왼쪽에 좌우 조향 버튼, 오른쪽에 액셀·브레이크 버튼을 배치하고 후진 전환 버튼을 구분하여 제공합니다.
- 조향과 액셀 또는 브레이크를 동시에 누르는 두 손 조작을 지원합니다.
- 후진 전환은 차량이 멈춘 상태에서만 가능합니다. 전진·후진 상태를 그림으로 구분합니다.
- 버튼을 놓거나 터치가 취소되면 누른 상태가 남지 않아야 합니다. 액셀과 브레이크가 동시에 입력되면 브레이크를 우선합니다.
- 게임 조작 중 브라우저의 스크롤·확대가 잘못 실행되어 조작을 방해하지 않도록 합니다.
- 큰 터치 영역과 충분한 간격을 확보하며, 조작 버튼이 차량·신호등·보행자를 가리지 않게 배치합니다.

후진 버튼의 전환 표시와 페달 동작은 시범으로 알려 줍니다. 어린아이가 실제로 이해하고 조작할 수 있는지는 보호자 동반 플레이에서 확인합니다.

### 화면과 카메라

- 장난감 같은 차량과 마을을 3D로 표현합니다.
- 카메라는 차량 뒤에서 조금 내려다보며 따라갑니다. 아이가 카메라를 따로 조작할 필요는 없습니다.
- 신호등, 보행자, 정지 위치와 진행 방향을 주변 장식보다 쉽게 구별할 수 있어야 합니다.
- 색상만으로 상태를 설명하지 않고 그림·형태·짧은 음성을 함께 사용합니다.
- 세로 화면에서는 가로로 돌리라는 안내를 제공합니다. 브라우저가 화면 방향을 강제로 고정할 수 있다고 전제하지 않습니다.

일시정지와 재개를 제공합니다. 앱 전환이나 브라우저가 보이지 않는 상태에서는 플레이·컴퓨터 차량·경기 시간을 함께 멈추고 입력을 해제합니다. 복귀 후에는 재개 동작을 거쳐 진행합니다.

## 안전 연습과 교육 내용

짧은 코스에서 운전 상황을 경험한 뒤, 중요한 순간에 같은 장소를 보행자 입장에서 보여 줍니다. 음성과 그림으로 아이가 길을 걸을 때의 행동을 연결해 설명합니다. 별도의 자유 보행 게임을 추가하는 것은 범위에 포함하지 않습니다.

| 주제 | 운전 체험 | 보행자 입장에서 전달할 내용 |
|---|---|---|
| 신호 기다리기 | 신호를 구분하고 정해진 위치에 멈추며, 안전한 때까지 기다립니다. | 횡단보도 앞에서 우선 멈추고 한 발 뒤에서 보행자 신호를 기다립니다. 빨간불에는 멈추고 초록불에 건너며, 아직 건너기 전에 초록불이 깜빡이면 다음 초록불까지 기다립니다. |
| 횡단 전 주변 차량 확인하기 | 횡단보도에 접근하는 차량과 보행자의 관계를 보고, 차가 완전히 멈추는 과정을 경험합니다. | 초록불로 바뀌어도 바로 건너지 않고 멈춘 뒤 왼쪽·오른쪽·다시 왼쪽을 봅니다. 운전자를 보며 손을 들어 내가 잘 보이게 하고, 차가 완전히 멈췄는지 확인한 뒤 걸으며 건너는 동안에도 차를 봅니다. |
| 교차로의 회전 차량 주의하기 | 교차로에서 회전하기 전 보행자를 확인하고, 보행자가 건널 때 기다립니다. | 초록불이어도 도는 차가 오는지 먼저 보고 멈췄는지 확인합니다. 키가 작아 운전자가 나를 못 볼 수 있음을 이해하고, 길모퉁이에서는 차도에서 멀리 떨어집니다. |

위 표의 내용은 각 연습의 핵심 규칙이며 매번 전달합니다. 이 밖에 공공기관의 미취학 아동 보행 안전 자료에서 찾은 추가 규칙(예: 어른 손 잡기, 주차된 차 사이로 다니지 않기, 통학버스 앞뒤로 건너지 않기, 골목길에서 멈추고 살피기, 신호등 없는 횡단보도 건너기, 비 오는 날 앞이 보이게 우산 들기)을 연습별로 나눠 두고, 연습을 다시 할 때마다 아직 보지 않은 규칙을 더해 보여 줍니다. 레이싱이 열린 뒤에도 안전 연습을 다시 하면 새 규칙을 배울 수 있습니다. 규칙 목록과 연습별 배정은 기능 명세(`specs/001-kids-driving-safety-game/spec.md`)의 "보행 안전 규칙 배정" 표를 따릅니다.

### 교육 표현 원칙

- 차량 신호와 보행자 신호를 구분하여 보여 주고 설명합니다.
- 손 들기와 운전자와 눈 맞추기는 운전자에게 내가 잘 보이게 하는 행동으로 설명하고, 항상 차가 멈췄는지 확인하는 행동과 함께 안내합니다. 손을 들면 차가 멈춘다고 받아들이게 하지 않습니다.
- 차 사이에서 뛰어나오기처럼 위험한 보행 행동은 그 행동을 하는 모습을 본보기로 보여 주지 않고, 운전자에게 어린이가 보이지 않는 이유와 올바른 행동으로 설명합니다.
- 깜빡이는 초록불에 기다리라는 안내는 아직 횡단을 시작하지 않은 상황에 사용합니다. 이미 건너는 아이에게 도로 중간에서 멈추라고 안내하지 않습니다.
- 위험 직전에 게임을 멈추는 연출은 학습을 위한 도움입니다. 현실의 차량도 자동으로 멈춘다고 받아들이게 만드는 안내를 사용하지 않습니다.
- ‘빨리 통과하기’보다 멈추기·살피기·기다리기를 직접 경험하도록 합니다.
- 잘못된 행동에는 사고·부상·위협적인 소리 대신 짧은 설명과 해당 구간의 재시도를 제공합니다.
- 튜토리얼 완료는 게임 안에서 필요한 행동을 수행했다는 기록입니다. 실제 교육 효과는 별도의 어린이 플레이 관찰에서 확인합니다.

### 연습의 완료 기준

각 안전 상황에서 안내된 정지·대기·출발 행동을 직접 수행하고 보행자 시점 안내를 경험하면 그 연습을 완료합니다. 단순히 끝 지점에 도착하거나 시간이 지나면 완료되는 방식으로 만들지 않습니다.

세 연습을 모두 완료하면 레이싱을 이용할 수 있습니다. 완료 전후 모두 원하는 안전 상황을 다시 연습할 수 있으며, 목숨 수나 실패 횟수 제한은 없습니다. 완료에 필요한 보행자 시점 안내는 그 연습의 핵심 규칙을 담은 안내이며, 추가 규칙은 완료 조건이 아닙니다.

## 레이싱 규칙

- 일반 도로와 구분된 전용 트랙에서 경주하며 보행자를 배치하지 않습니다.
- 플레이어 차량 1대와 컴퓨터 차량 3대가 경쟁합니다.
- 차량 선택에 따른 속도나 조작의 유불리가 없어야 합니다. 컴퓨터 차량도 공통 주행 규칙을 따르며, 난이도는 주행 경로와 반응을 조절하여 맞춥니다.
- 정상적인 플레이가 약 5분이 되도록 트랙 길이·차량 속도·컴퓨터 차량 난이도를 조정합니다.
- 바퀴 수는 트랙 조정 과정에서 1바퀴 또는 2바퀴 중 하나로 고정합니다. 첫 버전에 별도의 바퀴 수 선택 화면은 필요하지 않습니다.
- 약 5분은 예상 플레이 시간이며, 느리게 달렸다는 이유로 5분 시점에 경기를 강제로 끝내지 않습니다.
- 순위는 정상 진행 방향의 코스 진행도와 완주 순서를 기준으로 합니다.
- 차량끼리 접촉하면 파손·부상 표현 없이 감속합니다. 트랙 밖으로 나가 진행할 수 없다면 원래 진행 구간의 안전한 위치로 복귀합니다.
- 접촉이나 이탈로 경기 전체를 재시작하지 않으며, 복귀로 코스를 생략하거나 순위를 부당하게 올릴 수 없어야 합니다.
- 후진으로 결승선을 반복해서 넘거나 코스를 거꾸로 돌아도 추가 바퀴를 완료한 것으로 계산하지 않습니다.
- 완주 화면에는 순위와 완주 시간을 보여 줍니다. 해당 트랙의 최고 기록은 가장 짧은 정상 완주 시간으로 저장합니다.

## 소리와 배경음악

- 배경음악은 아이에게 익숙한 동요의 연주곡을 우선 사용합니다. 특정 곡이나 녹음 음원은 아직 선정하지 않았습니다.
- 곡과 녹음 음원이 공개 웹게임에 포함될 수 있는지 각각 확인하고, 필요한 제작자·출처·라이선스 표시를 제공합니다. 비상업용이라는 이유만으로 사용 가능하다고 판단하지 않습니다. [한국저작권위원회 안내](https://www.copyright.or.kr/customer-center/faq/list.do?categorycode1=&counselfaqno=47564&pageIndex=3&portalcode=04&searchkeyword=)
- 한국어 안전 안내가 나올 때는 배경음의 크기를 낮춰 안내를 들을 수 있게 합니다.
- 배경음과 안내·효과음을 끌 수 있어야 하며 설정은 브라우저에 저장합니다. 소리를 꺼도 핵심 안내는 그림과 시범으로 확인할 수 있어야 합니다.
- 사용자가 시작 버튼을 누른 뒤 소리를 활성화합니다. 모바일 브라우저의 자동 재생 제한을 고려한 요구사항입니다. [MDN 웹게임 오디오 안내](https://developer.mozilla.org/en-US/docs/Games/Techniques/Audio_for_Web_Games#autoplay)
- 음원 로딩이나 재생에 실패해도 화면 안내와 게임 진행은 가능해야 합니다.

### 개발 시 확인할 사항

- ZIP 안에 GLB/glTF 파일은 없습니다. 그래서 poly.pizza가 제공하는 GLB를 받아 쓰며, 받은 파일에서도 아래 사항을 확인합니다.
- 차량마다 크기와 좌표가 달라 방향·바닥 높이·화면상의 크기를 맞춰야 합니다.
- 사람 모델도 크기와 좌표가 제각각이므로 차량·마을과의 크기 비율을 맞춥니다. 차 안 탑승객이 보이도록 차종마다 앉힐 공간이 있는지 확인합니다.
- 외형 때문에 충돌 판정이나 카메라 시야에서 특정 차량이 유리하거나 불리해지지 않도록 합니다.
- 바나나 자동차의 텍스처는 ZIP 안에 포함되어 있으며, 변환 후에도 재질과 색상이 유지되는지 확인합니다.
- Chicken Guy와 Cool Bannana Guy의 텍스처는 FBX 파일 안에 들어 있으며, 변환 후에도 유지되는지 확인합니다. Turtle은 텍스처 없이 재질 색만 있습니다.
- 왜건 OBJ에는 노멀 데이터가 없어 조명 아래에서의 표현을 확인해야 합니다.
- 버기는 오브젝트가 101개로 나뉘어 있어 실제 렌더링 비용을 확인합니다.
- 차량 파일에는 준비된 애니메이션이 없습니다. 바퀴를 분리하여 회전시킬 수 있는지와 필요한 추가 작업은 확인되지 않았습니다.
- 원본 중 뼈대와 동작이 있는 것은 Chicken Guy뿐이었습니다. 2026-10-12 Cool Bannana Guy와 Turtle 수정본에도 뼈대와 기본 자세·손 들기·좌우 보기·앉기 동작을 추가하고 GLB 재로딩을 확인했습니다. 보행자 역할은 기존 결정대로 Chicken Guy이며, Chicken Guy의 교육용 손 들기·좌우 보기와 차량별 탑승객 배치는 게임 구현에서 확인합니다.
- Turtle ZIP의 `__MACOSX` 폴더는 macOS가 만든 부속 파일이므로 사용하지 않습니다.
- 원본의 압축 용량이나 메시 개수만으로 모바일 성능을 보장하지 않습니다. 차량 5종과 사람 모델 3종을 각각 실제 렌더링하여 확인합니다.

## 기록과 배포

### 브라우저에 남기는 기록

저장하는 정보는 튜토리얼 전체 완료 여부, 레이싱 최고 기록, 소리 설정입니다. 이름·생년월일 같은 개인정보를 입력받는 절차는 없습니다. 경기 중 위치나 미완료 연습을 재접속 후 이어 하는 기능은 첫 버전의 요구사항에 포함하지 않습니다.

저장 기능을 사용할 수 없거나 기록을 읽지 못해도 게임은 실행되어야 합니다. 이 경우 기록이 남지 않는다는 짧은 안내를 제공하고, 현재 실행 중에 완료한 튜토리얼로는 레이싱을 이용할 수 있게 합니다.

### GitHub Pages

게임은 브라우저 안에서 실행되는 정적 웹사이트로 배포합니다. GitHub Pages는 HTML·CSS·JavaScript를 게시하는 호스팅이므로 별도의 게임 서버 없이 배포하는 요구사항과 맞습니다. [GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

- 저장소 하위 경로로 배포해도 모델·음원·화면 파일을 정상적으로 불러와야 합니다.
- 시작 전 필요한 파일의 로딩 상태를 보여 주고, 필수 파일 로딩 실패 시 다시 시도할 수 있게 합니다.
- 동작 가능한 브라우저에서 로그인·앱 설치 없이 링크로 접속할 수 있어야 합니다.
- 3D 기능을 사용할 수 없는 환경에서는 빈 화면 대신 이해하기 쉬운 안내를 제공합니다.
- 설치형 앱과 오프라인 실행은 첫 버전의 지원 범위에 포함하지 않습니다.
